## Shared edit prompt

Use case: background-extraction.
Asset type: transparent foreground layer for a website project carousel.
Input image 1: edit target, the existing approved laptop-and-phone mockup.
Primary request: remove ONLY the surrounding environment. Extract ONLY the silver laptop and the upright black smartphone, keeping their existing website screens intact.
Scene/backdrop: actual transparent alpha everywhere outside the two devices. Remove the ivory wall, stone floor, palm shadows, ALL glass blocks/slabs/props, floor reflections and all environmental scenery. Keep a very faint soft semi-transparent contact shadow directly beneath the devices only; no floor patch.
Invariants: preserve the original 1536 x 1024 landscape canvas, exact camera angle, device positions, scale, silhouettes, laptop cropping at left edge, lighting on the metal, black bezels and phone position. Do not recenter, resize, rotate, restyle or regenerate the device arrangement. Keep ALL existing website content, photographs, UI colors, logos and typography on both screens unchanged. Do not reinterpret or retype screen text.
Output: a clean photorealistic foreground cutout suitable for compositing over an existing warm ivory background. Background must be genuinely transparent, NOT white, NOT a painted checkerboard. Crisp natural anti-aliased device edges, no pale rectangular halo, no new text, no new objects.

These are edits of illustrative generated mockups, not documentary screenshots. Original website captures remain separately linked. The shared daylight background is a separate static image and does not fade or swap with a project.
